# Спрос Wordstat по маркам и моделям (Россия)

Съём 01.11.2026 через XMLRiver (wordstat/new/json, регион 225 – Россия, июль–сентябрь 2026, среднее в месяц), 283 фразы, ~7 ₽.
Фразы – `zaprosy.py`, ответы – `wordstat-rf-2026-07-09.json` (avg и помесячно).

Оговорки: широкое соответствие. «ремонт geely», «ремонт changan», «ремонт gac», «ремонт tank» – в основном бензиновые модели;
«ремонт xiaomi», «сервис xiaomi» – телефоны, для машин не годятся. «то <марка>» – шумно. Интерес к модели («zeekr 9x») –
это покупка и парк, а не ремонт; ремонт по новым машинам пока мал, растёт вместе с парком.
